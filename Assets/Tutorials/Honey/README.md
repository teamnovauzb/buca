# Animated honey comparison tutorial

The original approved SeeTheDifference.png is preserved. ComparisonAnimationPlate.png
is a clean background derived from it, with static pucks/arrows removed and power
meters emptied for animation. The composition, wording and comparison design remain.

The runtime demonstration charges two meters, moves the weak puck into honey where
it decelerates and stops, and moves the strong puck through honey into the goal.
It loops every eight seconds. R restarts the demonstration. A 0.65-second eased
fade, scale and tilt brings the lesson on screen. No narration plays.

The printed Play button, Enter, Space or arcade Black continues. Gameplay input
and timer remain gated by LevelManager. Lessons show on every relevant level entry.
